# YaStudio — каталог услуг (Telegram Mini App)

Мини-приложение открывается из Telegram: бот @yastudiooo_bot → `https://t.me/yastudiooo_bot?startapp`.

- `js/data.js` — все тексты: услуги, продукты, схемы «Как это работает»
- `css/style.css` — дизайн
- `js/app.js` — логика и переходы
- `img/` — картинки

После правок поднимайте `?v=` в `index.html`, иначе Telegram покажет старую версию из кэша.
